# 要件定義

このサイトが**利用者から見てどう振る舞うか**を Gherkin 形式で記す。実装用語ではなく振る舞いで書き、
読んだ本人が齟齬に気づけることを優先する。機能に関わる変更は、着手前にここを追記・更新する。

対象は作品一覧ページ、作品ページ(作品ごとに1枚)、案内ページ(存在しない URL)。
作品一覧より後の機能は、特に断りがなければ**各作品ページ**の振る舞いを指す。

## 機能: 作品一覧から選ぶ

サイトのトップは作品の一覧になっている。

```gherkin
シナリオ: 作品の一覧を見る
  もし サイトのトップを開く
  ならば 公開中の作品がカードで並んでいる
  かつ 各カードには作品のタイトルとポスターが表示される

シナリオ: 作品ページへ移る
  前提 作品一覧を開いている
  もし 作品のカードを押す
  ならば その作品のページが開く

シナリオ: 作品ページから一覧へ戻る
  前提 作品ページを開いている
  もし ヘッダーのサイト名を押す
  ならば 作品一覧に戻る

シナリオ: どの作品も同じ見た目で読める
  前提 作品が2つ以上ある
  もし それぞれの作品ページを開く
  ならば 色の基調・文字・部品の見た目は共通で、作品ごとに違うのは差し色だけである
  かつ 作品にないセクションは表示されない(空の見出しだけが残ることはない)
```

## 機能: 本編を観る

利用者はトップの本編カードから、ページを離れずに短編を再生できる。

```gherkin
シナリオ: 本編カードから再生する
  前提 作品ページを開いている
  もし 本編のポスターカードを押す
  ならば 本編の再生画面が画面全体に重なって開く
  かつ 背景で流れていた動画は止まる

シナリオ: 本編の再生画面を閉じる
  前提 本編の再生画面が開いている
  もし 閉じるボタンを押す、または Esc キーを押す
  ならば 再生画面が閉じる
  かつ 背景の動画が再び流れ出す
  かつ 音は鳴り続けない

シナリオ: 埋め込みが再生できない場合
  前提 埋め込みの再生が利用できない
  もし 本編を開く
  ならば 同じ本編を自前の動画として再生できる
```

## 機能: 写真・動画の拡大表示

同じグループの写真と動画は、拡大表示のまま前後に送れる。

```gherkin
シナリオ: 写真を拡大する
  前提 記録セクションに写真が並んでいる
  もし 写真を1枚押す
  ならば その写真が拡大表示で開く

シナリオ: 同じグループを送る
  前提 写真を拡大表示で開いている
  かつ その写真は複数枚から成るグループに属している
  もし 「次へ」を押す
  ならば 同じグループの次の1枚が表示される
  かつ 写真と動画が混ざっていても1本の並びとして続けて送れる

シナリオ: 端に到達したら送れない
  前提 グループの最後の1枚を表示している
  もし 「次へ」の状態を見る
  ならば 「次へ」は押せない状態になっている

シナリオ: キーボードで操作する
  前提 拡大表示を開いている
  もし 左右の矢印キーを押す
  ならば 前後の1枚に切り替わる
  もし Esc キーを押す
  ならば 拡大表示が閉じる
  もし F キーを押す
  ならば 動画が全画面になる

シナリオ: 指で送る
  前提 拡大表示をスマートフォンで開いている
  もし 左右にスワイプする
  ならば 前後の1枚に切り替わる
  ただし 動画の再生バーを操作したときは切り替わらない

シナリオ: 枠が動かない ※マスト
  前提 拡大表示を開いている
  もし 縦位置の写真から別の縦位置の写真へ送る
  ならば 表示枠の大きさと、閉じる・左右のボタンの位置は変わらない
  もし 縦位置から横位置へ送る
  ならば 枠は横位置に合わせて広がり、ボタンもそれに追従する

シナリオ: 音の状態を引き継ぐ
  前提 拡大表示の動画を音ありで見ている
  もし 音を消して次の動画へ送る
  ならば 次の動画も音が消えたまま始まる
  かつ 送るたびに音が鳴り直すことはない

シナリオ: 拡大表示の外を押す
  前提 拡大表示を開いている
  もし メディアの外側を押す
  ならば 拡大表示が閉じる
```

## 機能: ページ上の動画

```gherkin
シナリオ: 見えている動画だけが動く
  前提 ページに複数の動画が置かれている
  もし ある動画が画面内に入る
  ならば その動画は自動で再生される
  もし 画面外へ出る
  ならば その動画は停止する

シナリオ: 自分で止める
  前提 動画が自動再生されている
  もし 動画を押す
  ならば 再生と一時停止が切り替わる
  かつ 一時停止した動画は、画面内に入り直しても勝手に再生を再開しない

シナリオ: 音を出す
  前提 音声のある動画が消音で流れている
  もし 消音の切り替えボタンを押す
  ならば 音が出る
  ただし 音量の調整は端末の音量ボタンに委ねる（画面上に音量バーは置かない）
```

## 機能: 制作過程を読む

```gherkin
シナリオ: 撮影前後の色の違いを比べる
  前提 カラーの比較スライダーが表示されている
  もし つまみを左右に動かす（ドラッグ、またはキーボード）
  ならば 補正前と補正後の境目がその位置まで移動する

シナリオ: ショットリストの帯を送る
  前提 ショットリストの写真が横に並んでいる
  もし 横方向にドラッグする
  ならば 並びがその分だけ流れる
  かつ ドラッグの直後は写真が拡大表示で開かない（掴んだだけで開かない）

シナリオ: 制作資料にたどり着く
  前提 本文に「ショットリスト」「香盤表」等の語が出てくる
  もし その語を押す
  ならば 資料セクションの該当カードまでページが移動する
  もし そのカードを押す
  ならば 対応する制作資料の PDF が別タブで開く

シナリオ: ロケ地を確かめる
  前提 本文にロケ地名が出てくる
  もし ロケ地名を押す
  ならば その場所の地図が別タブで開く
```

## 機能: ページ内の移動

```gherkin
シナリオ: 見出しに隠れない
  前提 上部に固定のヘッダーがある
  もし ナビゲーションから任意のセクションへ移動する
  ならば そのセクションの見出しはヘッダーに隠れず、余白を空けて表示される

シナリオ: 存在しないページ
  もし サイト内の存在しない URL を開く
  ならば 本編と同じトーンの案内ページが表示される
  かつ 作品一覧へ戻る導線がある
```

## 機能: スマートフォンでの表示

```gherkin
シナリオ: 縦に積む
  前提 画面幅が 48em（およそ768px）以下である
  もし 任意のセクションを見る
  ならば 横並びの段組みは解除され、内容が上から縦に積まれる
  かつ 横方向にページがはみ出してスクロールすることはない

シナリオ: 拡大表示のボタンが画面外に出ない
  前提 スマートフォンで拡大表示を開いている
  もし 閉じる・左右のボタンを見る
  ならば すべて画面内に収まっている
```

## 機能: 作品と本文を管理する

管理者(サイトの持ち主)は、自分の PC の管理画面からサイトの中身を編集する。
コードを書き換えずに済むことを目的とする。

```gherkin
シナリオ: 本文を直す
  前提 管理画面で作品を開いている
  もし 本文やキャプションを書き換えて保存する
  ならば 確認用の表示に、書き換えた文が同じ見た目で反映される

シナリオ: 写真・動画・資料を差し替える
  前提 管理画面で作品を開いている
  もし 写真・動画・制作資料を追加、差し替え、または並べ替える
  ならば 確認用の表示に、その順番で並ぶ
  かつ 拡大表示で送る順番も同じになる

シナリオ: 撮影回を足す
  前提 管理画面で作品の制作過程を開いている
  もし 撮影回を1つ追加し、日付・ロケ地・クルー・本文・写真を入力する
  ならば 制作過程に既存の撮影回と同じ形式で1回分が加わる

シナリオ: 作品を増やす
  前提 管理画面を開いている
  もし 新しい作品を追加し、使うセクションと差し色を選んで入力する
  ならば その作品のページが既存の作品と同じ見た目でできる
  かつ 作品一覧にカードが加わる

シナリオ: 下書きは公開されない
  前提 作品を下書きのまま保存している
  もし サイトを公開する
  ならば その作品は作品一覧にも載らず、ページも公開されない
```

## 機能: サイトを公開する

```gherkin
シナリオ: 編集内容を公開する
  前提 管理画面で編集を終えている
  もし 公開の手順を実行する
  ならば 公開中のサイトに編集内容が反映される
  かつ 公開中のサイトから管理画面にはたどり着けない

シナリオ: 公開前に表記の誤りに気づける
  前提 本文に表記ルール(英語の綴り・記号・キャプションの句点など)に反する箇所がある
  もし 公開の手順を実行する
  ならば 公開する前にその箇所が知らされる
```

## 満たすべき前提（全機能に共通）

```gherkin
シナリオ: 動きを減らす設定
  前提 端末で「視差効果を減らす」設定が有効になっている
  もし ページを見る
  ならば スクロールに連動する演出は行われない

シナリオ: 公開されている素材が欠けない
  もし 公開されたページを開く
  ならば 参照している画像・動画・PDF はすべて表示・再生できる
  かつ 読み込めないリンク先は存在しない
```

最後のシナリオは `node scripts/check.mjs` で機械的に検証している。
