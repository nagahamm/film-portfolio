# 詳細設計

**いま構造がどうなっているか**を書く。変更の理由や経緯は Issue とコミットに残し、ここには残さない。
構造に関わる変更は、実装より先にここを更新する。

見た目(色・タイポグラフィ・コンポーネントの意匠)は
`.claude/skills/portfolio-design/` が持つ。ここでは扱わない。

## 全体像

ビルド工程を持たない静的サイト。Netlify がリポジトリ直下をそのまま配信し、
生成物・中間ファイル・パッケージ依存を一切持たない。この制約を崩さないこと
(ツールを1つ入れると「手元では動くが本番と違う」状態が生まれるため)。

```
ブラウザ
  ├── index.html      構造と本文（唯一のページ）
  ├── css/style.css   :root のトークン層 → 各コンポーネント
  ├── js/main.js      振る舞い（状態クラスの付け外しに徹する）
  └── assets/         画像・PDF（動画だけは R2 から）
```

## 責務の分離

| 層 | 担当 | 触ってはいけないこと |
| :--- | :--- | :--- |
| `index.html` | 構造と本文 | 装飾(インラインスタイル禁止) |
| `css/style.css` | 装飾のすべて | — |
| `js/main.js` | 状態の切り替え | スタイル値の直接指定(状態クラスを付けて CSS に委ねる) |

JS が CSS の値を直接書き込む例外は `--masonry-gutter` の読み取りのみ。
これは CSS 側を唯一の定義とし、JS がそれを読む向きに固定している。逆向きにしない。

## CSS の構造

1. `DESIGN TOKENS`(`:root`) — 色・比率・寸法・モーションの唯一の定義
2. `RESET & BASE` → `TYPOGRAPHY PRIMITIVES` — 全体の土台
3. コンポーネント各節 — **ページの登場順**に並べる
4. `UTILITIES` → `RESPONSIVE` — 最後

新しい節を足すときは登場順の位置に挿入する。末尾に足していくと対応関係が崩れる。

## JS の構成

`js/main.js` は上から順に、独立した小さなブロックの列として並ぶ。相互に状態を共有しない。

| ブロック | 目印 | 役割 |
| :--- | :--- | :--- |
| フェードイン | `.fade` | スクロール連動の表示。IntersectionObserver |
| Masonry | `.masonry-grid` | 高さの揃わない写真の配置 |
| アルバム割り当て | `[data-album]` | 拡大表示のグループ分け |
| カルーセル | `[data-carousel]` | Episode / Craft 共通 |
| ミュート切替 | `.ep-video-mute` | 音声のオン/オフ |
| 画面内再生 | `.carousel-slide video` | 見えている動画だけ再生 |
| 比較スライダー | `[data-compare]` | Before/After |
| ショットリスト | `.shotlist-marquee` | 横ドラッグ |
| メディアモーダル | `#img-modal` / `#video-modal` / `#film-modal` | 拡大表示 |

新しい振る舞いは既存ブロックに混ぜず、独立したブロックとして足す。

## メディアモーダル

このサイトで最も込み入っている箇所。**先に読むこと。**

### アルバム
`[data-album]` を持つ `img` / `video` を DOM 順にグループ化する。写真と動画が混在しても
1本の連続した並びとして前後送りできる。同じ `src` は重複排除される。

### 枠 (`.modal-stage`)
`.modal-stage` が「比率の固定枠」と「閉じる・左右ボタンの位置基準」を兼ねる。
表示中のメディアの実寸(`naturalWidth`/`videoWidth`)から縦横を判定し、
`.is-portrait-modal` / `.is-landscape-modal` を **この要素に** 付ける。他の要素に付けても効かない。

枠のサイズが送るたびに動くと利用者の目線がぶれるため、一度広げた枠は
同じアルバムを見ている間は縮めない(`widenFrames`)。

### ボタン位置
`--modal-btn-x` / `--modal-btn-y` の **符号だけ** で枠の内/外が切り替わる
(負=枠外・PC、正=枠内・モバイル)。個別セレクタで位置を上書きしない。

### 音
モーダル内で音の状態を引き継ぐ(`modalMuted`)。既定は音あり。一度消したら
以降に開く動画も消音で始まる。前後送りのたびに音が鳴り直さないための設計。

### キーボード
開閉のたびにリスナーを登録し直さず、`isOpen()` で判定する常設リスナーにしている。
二重発火を防ぐため。全画面中はネイティブのシーク操作を優先し、左右キーを奪わない。

### 本編 (`#film-modal`)
Instagram の埋め込み(`iframe`)。埋め込みは自前の高さを持ち比率が読めないため、
`--modal-embed-w` で幅だけ固定し、高さは枠に預ける。比率判定の対象外。
埋め込みが再生できない場合に備え、自己ホストの本編(`#modal-video-player` の `src`)を
フォールバックとして持つ。

## メディアの配信

| 種類 | 置き場所 | 経路 |
| :--- | :--- | :--- |
| 画像・PDF | リポジトリ内 `assets/` | Netlify がそのまま配信 |
| 動画 | **Cloudflare R2 の `videos/`** | `netlify.toml` の 302 リダイレクト |

動画をリポジトリに入れない理由は、Git の履歴を実質不可逆に膨らませるため。
HTML 側は `assets/videos/...` の相対パスのままでよく、配信元の差し替えは
`netlify.toml` の URL だけで済む。

**動画を追加するときは R2 へのアップロードと `netlify.toml` への追記が対**。
片方だけだと本番で 404 になる。`node scripts/check.mjs` がこの対応漏れを検出する。

## キャッシュ

`/assets/*` は1年。ファイル名に撮影日と用途を含み、内容が変わればファイル名も変わる運用が前提。
**同じ名前のまま中身を差し替えてはいけない。** `/css/*` と `/js/*` は1時間。

## レスポンシブ

ブレークポイントは `48em` と `30em` の2つのみ。3つ目を作らない。
`48em` 以下では Grid / Subgrid / 中央揃えを完全にリセットして縦積みにする。

## 検証

`node scripts/check.mjs`(依存パッケージなし)。JS の構文、参照アセットの実在、
R2 動画のリダイレクト対応、未参照リダイレクトの残留、インライン動画の必須属性、
インラインスタイルの混入、未定義の CSS 変数、行き先の無いアンカーを見る。
