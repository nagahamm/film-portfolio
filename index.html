  • 監督
    Problem (課題)

    参考映画・アニメ等の画像共有だけでは、経験の浅いカメラマンと構図や画角(レンズ感)の認識ズレが発生した

    Action (対策)

    参考カットが無い場合はAI画像生成で脳内イメージを具体化。演者の動作・レンズ倍率(例: iPhone 48mm / 2x)・カメラワーク(手持ちTrack)までショットリストに緻密に指定

    Result (成果)

    感覚に頼らず意図通りの画を確実に再現でき、現場の迷いやテイク数を大幅削減

  • 撮影(技術)
    Problem (課題)

    前回、マイク接続ミスで3時間分の音声が未収録になり再撮影が発生した

    Action (対策)

    撮影ごとに録音を都度チェック

    Result (成果)

    ミラーリング機器接続時の音ズレに気づき外して撮影。後日の撮り直しリスクを防止

  • 編集(ポスプロ)
    Problem (課題)

    映像素材数が膨大で整理が追いつかず、編集時に目的のファイルを探し回るタイムロスが発生していた

    Action (対策)

    映像素材を撮影単位で整理し、構成に合わせてシーケンス(タイムライン)を8つに事前分割。バックアップも徹底

    Result (成果)

    先行録音した音声素材も対応シーケンスへ迷わず配置でき、素材迷子をゼロにして編集作業を劇的に効率化

  • 制作進行
    Problem (課題)

    前回、予定(21:00〜01:00)に対し03:30まで大幅超過した

    Action (対策)

    初回撮影時にセッティングや移動時間を含めた香盤表を制作し、タイムスケジュールを可視化

    Result (成果)

    当日の進行遅延を防ぐ効果を実感するも、全行程における香盤表の運用継続が新たな課題に

  • 制作進行
    Problem (課題)

    iPhoneをメインカメラとして使用するため、端末内のみで資料管理すると撮影中の確認ができず進行が停滞し、バッテリーも激しく消耗した

    Action (対策)

    印刷した紙のショットリスト(予備含む)をメイン運用し、スマホにバックアップ保存

    Result (成果)

    撮影の手を止めず電池も温存する二重体制を徹底

Process

制作プロセス

2025.11

脚本・ロケハン開始

「Save the Cat」などの脚本術をベースに、Geminiをアイデアの壁打ち相手として活用しながらプロットを構築。ジャンルは「金の羊毛」型のアドベンチャーファンタジーに設定し、並行してオーストラリアの雄大な自然を最大限に活かせるロケーションの選定を進めました。

「撮れる画」を確実にするための徹底的なロケハン

イメージと近い理想の場所の選定を行うだけではなく、構図も意識しながら

別のアングルでも…

雰囲気が崩れるので、人工的な桟橋のようなものを写さないようなアングルを探す

採用したアングル

ロケハンでは、単に理想の風景を探すだけでなく、本番を想定したシミュレーションを重視しました。平日や休日で人出がどう変わるかを把握するため、可能な限り複数回現地へ足を運んでいます。早朝撮影など、一般の人が映り込まないよう最大限の工夫を凝らしましたが、完全な排除は難しいため、構図の工夫でカバーする現実的な判断も下しました。

2025.12 – 2026.02

キャスティング・準備

現地で出会った仲間たちに制作資料を提示し、直接説得してチームを編成。衣装手配と並行して、撮影未経験のメンバーへの技術共有(カメラ、マイク、NDフィルターの操作など)も行いました。単なる作業指示ではなく「各ショットで何を狙うのか」という画の意図まで共有しました。自らの本気度が、彼らを動かすことが出来たと感じています。

カメラテスト② 気づき

ワイングラスにマジックアームでカメラを固定し、飲む動作に追従する同調カット(ロール移動)を検証。カメラマンの姿勢保持が不十分で、スムーズなロール回転が得られない課題を発見

役割を交代しながら、カメラ指導

採用したショット

クランクイン前に2度の入念なカメラテストを実施しました。カメラテスト①(1/28・水)は助演のたかしさんとルームメイトの協力を得て、機材テストからカメラワークの指導まで約3時間かけて検証しました。この結果を基に、撮影①(クランクイン)に向けた香盤表とタイムスケジュールを構築しました。さらにカメラテスト②(2/22・日)では、新たに追加されたショットリストの実証を行い、本番の撮影①に向けた手順の検証とスケジュールの微調整を図りました。

2026.02.28 – 2026.05.21

撮影

メンバーのスケジュール調整や見積もりの甘さから、当初3回を想定していた撮影は結果的に全10回に膨れ上がりました。緻密な香盤表の運用が初回のみで途絶え、その後は紙のショットリスト(Milanote)へメモでの運用にシフトしたことは進行管理上の反省点です。しかし、本プロジェクトでは撮影期間中にカメラマンが4人入れ替わるという状況下でありながら、現場の撮影スピードは回を追うごとに向上しました。これはショットリストでのレンズ倍率・カメラワークの緻密な数値指定や、事前イメージの共有など、監督としてのディレクション指示を徹底的に言語化・システム化したためです。特定の相手との慣れに頼るのではなく、「誰がカメラを持っても迷わず即座に意図通りの画を撮れる現場回し」を確立したからこそ、全10回の撮影を最後までクオリティを落とさず完遂することができました。

撮影① 天候トラブルへの即応

雨季の豪雨による増水で初期エリアが立ち入り不能に。即座に上流ポイントへ切り替えて撮影を完遂

撮影①(2/28・土)(ロケ地: Cedar Creek Falls / クルー: 4名)。オーストラリア特有の雨季による急な増水で目的地の滝へ入れなくなるトラブルが発生。現場の迅速な判断で即座にスケジュールを繰り上げ、上流の安全なポイントへ撮影地を変更することで、撮影をストップさせることなく完遂しました。

撮影① 機材管理・オペレーションの再構築

初回撮影時、機材の雑多な収納が原因で背景に見える荷物の一部紛失が発生

用途別(機材・食料・衣類)にバスケットを整理。徒歩15分の移動負荷を考慮し車内残置ルールも徹底

撮影①(2/28・土)の機材紛失を反省し、現場オペレーションを即座に再構築。機材・食事・衣類などの「用途別バスケット管理」を導入しました。また、現場まで徒歩15分のアプローチがあるため、不要な荷物は車内に残して移動負荷を軽減しました。さらに車両への搬出入時には「写真照合チェック」を徹底し、以降の機材紛失をゼロに抑えました。

撮影② 痛恨のミスと熱量が引き寄せた奇跡

カメラテスト時と同様、現場では役割を交代しながら理想のアングルになるまで写真を撮り検証

地図に目線を誘導しつつ、視線の先に滝が映り込む理想の構図・アングルを模索

REC押し遅れのアクシデント発生も、現場のギャラリーから映像を提供してもらい奇跡的にリカバリー

撮影②(3/14・土)(ロケ地: Gardners Falls / クルー: 2名)。たくみさんに初めてカメラマンを任せるにあたり、食事や移動の時間を活かしてショットリストの意図を事前共有。現場では役割を交代しながら理想のアングルや構図を細かく擦り合わせました。

そして川へのダイブシーン。まさかの「RECボタン押し遅れ」で撮り逃す痛恨のアクシデントが発生。「せっかくの素材が撮れていない…もう一回飛び直すしかないか」と憔悴する一方で、現場は前日までの豪雨で増水した激流へ飛び込む過酷な撮影に大盛り上がり。面白がって見ていた地元の子たちが、大歓声をあげ、いつの間にか僕はヒーローと化していました。

ダメ元で彼女たちに声をかけてみると、なんとスマホで完璧なアングルからバッチリ撮影してくれており、その場で映像を提供してもらうことで奇跡的に最高の素材を回収・補完できました。ピンチを今回の撮影での熱量が劇的なドラマに変えた、忘れられない撮影となりました。

自然環境を相手にする難しさと覚悟

強い日差しで防水ケースに入れたiPhoneの画面が見えず被写体を見失い、確認のためのケース開閉を繰り返すうちに浸水し撮影続行が困難に

iPhoneを防水ケースから出して直撮りを敢行。見事、本編カットとして採用

波のタイミングが合わず、強すぎて流されたり弱すぎて波が立たなかったりと、自然のタイミングを狙う撮影の難しさを痛感

滝(Twin Falls)での撮影は片道2時間半の移動時間と冷水が大きな課題だったため、海(Mooloolaba Beach)での再ロケハン(4/11・土)を撮影期間中に実施。「背景が変わっても違和感なく見え、十分カットが繋がる」と演出上の成立を検証・確信しました。これにより撮影⑥(4/19・日)(ロケ地: Twin Falls / クルー: 2名)では過酷な環境に難色を示すキャストを説得して撮影を必要最小限のカットに抑制。残りのカットは事前検証済みの海へとロケ地を変更し、撮影⑧(5/3・日)(ロケ地: Mooloolaba Beach / クルー: 3名)へとリスケジュールしました。さらに、日が差して水温の上がるタイミングを狙うことで長時間の撮影を完遂。現場では強い日差しで防水ケースに入れたiPhoneの画面が見えず、手持ちの服を被って反射を抑えながら画面を確認・撮影してもらうという試行錯誤を行いましたが、最終的には映像表現を最優先し、iPhoneの水没リスクを承知の上でケースから出して直撮りの決断を下しました。

現場トラブルを演出に変える柔軟な構成力

「…奮い立たされるんだ」と感情曲線のピークで、映像は回想から現代へ。音声は現場の生セリフと後撮り音声を重ねた演出

助演が長セリフを現場で忘れてしまう問題に対し、即座に手持ちから三脚撮影へ切り替え、カメラ横に即席のカンペを配置。しかし、目線の違和感や文字サイズの限界を瞬時に見抜き、現場では途中のセリフを削って必要最低限に絞りました。削ったセリフは回想シーンに重ねるモノローグだったため後撮りへ切り替えました。編集では現場音と後撮り音の音質差が課題となりましたが、BGMの開始タイミングに合わせて切り替えたり、声を映像に重ねる工夫を実施しました。さらに「…俺も、やらなきゃって。奮い立たされるんだ」の「奮い立たされるんだ」という感情のピークでは、後撮り音声に現場で収録した生のセリフを重ねてミックスし、その最高のタイミングで画面を回想から現代へ戻すことで、トラブルを効果的な演出へと着地させました。

2026.05.23

帰国

オーストラリアでのワーキングホリデーを終え、帰国。

2026.06 – 2026.07

編集・カラー

「語るより魅せろ」という映画の原点を軸に、編集段階でも脚本やショットリストに縛られず「映像としてどちらが面白いか」を優先してカット構成を大胆に再構築しました。

視線誘導と脳内補完を生むカット割り

演者の動作やセリフのタイミングに合わせたマッチカットを多用し、観客の脳内で自然にカットが繋がるリズムを追求したカット割り

撮影②(3/14・土 15:40)
撮影①(2/28・土 10:20)

ショットリストを参照しながら撮影を進めたものの、セリフの撮り忘れにより別日程での追加撮影が必要となったカット。同じ場所(ロケ地: Cedar Creek Falls)だが、別日程・別時間帯で撮影した2カット間のトーン(色味・空気感)の一致を目指したカラーマッチング

演者の動作やセリフのタイミングに合わせたマッチカット(動作の繋がり)を多用し、観客の脳内で自然にショットが繋がるリズムを追求しました。別日程の撮影による天候や時間帯ごとの光の違いに対して、引きのショットや別アングルを効果的に挟み込みつつカラーグレーディングを実施しました。トーンの完全な一致には課題を残しつつも、動作と視線の連続性を保ち、ストーリーの流れを途切れさせない工夫を凝らしました。

1フレームへの執着と完遂力

何週間もタイムラインと向き合う中で「作品の面白さ」を見失いかける葛藤(ゲシュタルト崩壊)もありましたが、1フレーム単位でカットを詰めたり遅らせたりと何回、何十回、何百回もトライ＆エラーを重ね、映像と音(間の取り方)の最適解を泥臭く検証し続けました。一過性のモチベーションに頼るのではなく、「撮影に関わってくれた方へ最高の形で届ける」という責任感を原動力に、妥協せず最後まで作品を作り切りました。

  • 脚本
    Problem (今回の課題・反省)

    当初03:30あった尺を03:05まで削ったものの、見せたいショットを優先した結果これ以上短縮できず、Instagramの03:00制限を超過してリーチ機会を逃した

    Next Action (次回の改善策)

  • 監督
    Problem (今回の課題・反省)

    撮影を任せられなかったサポートメンバーに対し、役割の意図や重要性を言語化しないまま作業依頼し、モチベーションを保てず途中離脱させてしまった

    Next Action (次回の改善策)

    裏方やサポート作業であっても「なぜその役割が作品制作に必要なのか」という全体像と価値を事前に言語化して共有し、全員が目的意識を持って参加できる動機付けと配慮をする

  • 撮影(技術)
    Problem (今回の課題・反省)

    録音環境の制約によりノイズや音割れが発生し、編集でノイズリダクション等のリカバリーを試みたが限界があった

    Next Action (次回の改善策)

    外部マイクの適切な配置と事前のゲイン(録音レベル)調整を行い、編集(ポスプロ)に依存しない「収録段階での音質確保」を最優先とする

  • 制作進行
    Problem (今回の課題・反省)

    全体の制作期間やデッドラインを設定しておらず全10回に膨大。さらに香盤表運用も途絶え帰国後も追加撮影が発生した

    Next Action (次回の改善策)

    企画段階で全行程の香盤表を完備し、クランクアップと完成のデッドラインを厳格に設定。逆算したスケジュール管理をする
